# Full-Stack Course - Database Tasks

My solutions for the database tasks in a full-stack development course. Written in T-SQL for SQL Server.

## Contents

- `task2-1` - ER diagram for a company database (employees, departments, projects, dependents)
- `task2-3.sql` - builds the CompanyDB schema from that diagram
- `task3-1.sql` - query practice on a store database (filtering, sorting, grouping, TOP)
- `task3-2.sql` - CompanyDB schema with constraints and foreign keys

## How to run

Open a .sql file in SQL Server Management Studio or Azure Data Studio and run it. Each script starts with `USE <database>` and creates its own tables.
